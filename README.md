# 🥠 Fortune Trails

A cute 2D zodiac-based fortune game created in Godot for a university club fair.

Players enter their birth year to receive their Chinese zodiac character, collect coins while avoiding bombs, and unlock a fortune from the capsule machine.

## 🌟 Features

- 12 Chinese zodiac characters
- Birth-year based zodiac selection
- Coin collection system
- Bomb and health system
- Animated capsule machine
- Random fortune system
- Custom 2D artwork and UI
